# New DP native-H5 evaluation

Evaluate a current new-DP sampler ONNX with this repository's existing open-loop
metrics and closed-loop renderer. The only data format is native H5 version 4:
open-loop also needs its Parquet frame index, while closed-loop uses a route-H5
manifest. This package does not convert NPZ files or ROS bags.

The standard data root is:

```bash
DATASET_ROOT=/media/temkeikem/SSD2T/Diffusion-Planner-Meta-Repository/data/new_DP_dataset
PYTHON=../new-DP/.venv/bin/python
MODEL=/path/to/diffusion_planner_sampler.onnx
```

## Open-loop

An open-loop matrix maps each metric to native frame references:

```json
{
  "centerline": [{"h5_path": "h5/open_loop_override/centerline/example.h5", "frame_index": 0}]
}
```

The referenced H5 may contain one frame or a complete route. The corresponding
Parquet index is authoritative and must contain `h5_path`, `frame_index`, and
`frame_time_ns` for every selected frame.

```bash
PYTHONPATH=.:diffusion_planner "$PYTHON" -m new_dp_h5_eval.open_loop \
  "$DATASET_ROOT/override_data/open_loop_basic_h5.json" \
  "$DATASET_ROOT/override_data/h5/open_loop_basic/index.parquet" \
  "$MODEL" \
  /tmp/new_dp_open_loop_basic

PYTHONPATH=.:diffusion_planner "$PYTHON" -m new_dp_h5_eval.open_loop \
  "$DATASET_ROOT/override_data/open_loop_override_h5.json" \
  "$DATASET_ROOT/override_data/h5/open_loop_override/index.parquet" \
  "$MODEL" \
  /tmp/new_dp_open_loop_override
```

Some packaged indexes predate the final collection directory name. The reader resolves
those entries relative to the index collection; matrices always use the current H5 path.

## Closed-loop

A closed-loop manifest maps each group to complete-route H5 paths. A route may be
limited with `{"h5_path": "...", "frame_start": N, "frame_stop": M}`.

```bash
PYTHONPATH=.:diffusion_planner "$PYTHON" -m new_dp_h5_eval.run_all_groups_closed_loop \
  --closed_loop_h5_root \
    "$DATASET_ROOT/site_data/closed_loop_site_data_h5.json" \
    "$DATASET_ROOT/override_data/closed_loop_override_h5.json" \
  --closed_loop_object_modes objects noobj \
  --model_path "$MODEL" \
  --out_root /tmp/new_dp_closed_loop
```

The runner retains the standard closed-loop rendering, distributed aggregation, and
result layout. Native route H5 is generated by
`new-DP/scripts/dataset/create_h5_dataset.py`.
