# ROSBAG to HDF5 conversion

## Input JSON

The converter accepts a JSON array containing absolute NPZ paths.

```json
[
  "/mnt/storage_rdma/diffusion_planner/dataset/20260814_basic_dataset/x2_dev/.../frame_0001.npz",
  "/mnt/storage_rdma/diffusion_planner/dataset/20260814_basic_dataset/x2_dev/.../frame_0002.npz"
]
```

The existing Open Loop matrix format is also supported. Each key is treated as a group name, and the values are lists of absolute NPZ paths.

```json
{
  "centerline": [
    "/mnt/storage_rdma/diffusion_planner/dataset/20260814_basic_dataset/x2_dev/.../frame_0001.npz"
  ],
  "departure": [
    "/mnt/storage_rdma/diffusion_planner/dataset/20260814_basic_dataset/x2_dev/.../frame_0002.npz"
  ]
}
```

The array format is the recommended input for conversion. The matrix format is useful when the same JSON is also used to separate evaluation metrics.

## Scenario-based matrix schema

This is a scenario-based Open Loop evaluation. Each scenario is represented by one NPZ path. The `centerline` and `departure` arrays specify the evaluation group for each scenario.

```json
{
  "centerline": [
    "/absolute/path/to/scenario_0001.npz",
    "/absolute/path/to/scenario_0002.npz"
  ],
  "departure": [
    "/absolute/path/to/scenario_0003.npz"
  ]
}
```

All paths must be absolute NPZ paths. Each NPZ must have a same-stem sidecar JSON, such as `scenario_0001.json`. The sidecar timestamp is used to locate the corresponding ROSBAG frame.

The NPZ files are used only to identify the source ROSBAG and target timestamp. Their tensors are not used for HDF5 generation. The `.json` sidecar next to each NPZ provides `timestamp` and `map_version_id`.

## Output

For each NPZ, one HDF5 file containing one frame is generated. `index.parquet` contains the HDF5 path, frame index, timestamp, and metadata.

```text
output_root/
├── frames/
│   ├── frame_0001.h5
│   └── frame_0002.h5
└── index.parquet
```

Each HDF5 contains:

```text
frames/    model inputs and labels generated from ROSBAG
metadata/  frame_time_ns, speed, yaw rate, turn indicator, etc.
```

The converter reads only the Route-message chunk and the chunks required around each target timestamp.

## Arguments

| Argument | Description |
|---|---|
| `matrix` | Path to the NPZ path-list JSON or Open Loop matrix JSON. |
| `rosbag_root` | Root directory containing the source ROSBAG directories. |
| `output_root` | Directory where per-frame HDF5 files and `index.parquet` are written. |
| `--dataset-root-name` | Dataset directory name in an NPZ path. Default: `20260814_basic_dataset`. |
| `--traffic-light-timeout` | Maximum allowed age of Traffic Light data in seconds. Default: `0.2`. |
| `--neighbor-timeout` | Maximum allowed age of neighbor tracking data in seconds. Default: `0.3`. |
| `--workers` | Number of parallel worker processes. Default: up to `4`. |

## Command

```bash
source /opt/ros/humble/setup.bash
source ros2_ws/install/setup.bash

PYTHONPATH=packages/diffusion_planner/src:$PYTHONPATH \
python3 packages/diffusion_planner/dataset/convert_matrix_rosbag_to_h5.py \
  evaluation_data/open_loop_npz_paths.json \
  /mnt/storage_rdma/diffusion_planner/rosbags_from_label \
  evaluation_results/open_loop_matrix_rosbag_per_npz \
  --workers 4
```

## Validation and visualization

### Inputs

```text
matrix_json     JSON containing centerline/departure NPZ paths
parquet_index   HDF5 frame references generated by the converter
onnx_weights    ONNX model file
```

The matrix JSON is used to preserve the scenario evaluation group and sample order. NPZ tensors are used only by the legacy scene visualizer; model inputs are loaded from HDF5 through `PlannerDataset`.

### Command

```bash
PYTHONPATH=packages/diffusion_planner/src python3 \
  packages/diffusion_planner/dataset/run_validation.py \
  evaluation_data/open_loop_matrix.json \
  evaluation_results/open_loop_matrix_rosbag_per_npz/index.parquet \
  /path/to/model.onnx \
  evaluation_results/open_loop_matrix_validation \
  --seed 0
```

### Arguments

| Argument | Description |
|---|---|
| `matrix` | Matrix JSON containing evaluation groups and NPZ paths. |
| `parquet` | Parquet index generated by the converter. |
| `onnx` | Path to the ONNX model weights. |
| `output` | Directory for summaries, predictions, details, and PNGs. |
| `--seed` | Base random seed for initial diffusion noise. Default: `0`. |

### Outputs

```text
output/
├── summary.json
├── predictions.npz
├── details/
│   ├── centerline/details.jsonl
│   └── departure/details.jsonl
└── visualization/
    ├── centerline/frame_XXXX.png
    └── departure/frame_XXXX.png
```
